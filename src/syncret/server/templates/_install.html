  1. Get the client: git clone https://github.com/pawtaetoe/syncret
  2. Run its installer and paste the token when it asks.

    Linux or macOS

    bash syncret/client/install.sh --url {{ url }}

    Windows (PowerShell)

    powershell -ExecutionPolicy Bypass -File syncret\client\install.ps1 -Url {{ url }}
  3. On Linux, keep it syncing while you are logged out: sudo loginctl enable-linger $USER
